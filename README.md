**Due date**: 2026/11/10

Original requirements can be found [in Dropbox](https://www.dropbox.com/scl/fo/4bp4ovjgmvhzgnklmb61y/AMg3TETJ_Dm9l2pRrEwD0PM/DSProgAssn/DSprogassn.docx?rlkey=cbwmnxydewf1kb0ceammigy3k&e=2&dl=0).

Create a stack, queue, and deque data structure by extending either Vector or ArrayList and implementing individual interfaces specific to each of the three classes.

Implement an interactive program with a main menu for which data structures to use.
Implement submenus for reading, adding, removing, and printing elements.

All classes, methods, andn fields should be accompanied by Javadoc comments.
The comments should outline design decisions and functionality.

## Requirements
### Classes created
- Stack
- Queue
- Deque
- main user class

### Functionality implemented
- Interactive user portion
  - Menu
    - Create object
    - Delete object
    - List objects
    - Print object
- Each class should have an iterator
